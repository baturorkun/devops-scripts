# Get Free SSL Certs

There are many ways to get free SSL for 3 months. I like and use acme.sh. Acme supports many CA and supports many auth modes.

ZeroSSL.com CA(default)
Letsencrypt.org CA
BuyPass.com CA
SSL.com CA
Google.com Public CA
Pebble strict Mode
Any other RFC8555-compliant CA

To get extra information and installation, please follow the URL:

https://github.com/acmesh-official/acme.sh


To run these scripts in this directory, clone the "acme.sh" repository at first.
